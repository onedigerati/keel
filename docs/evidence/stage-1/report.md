## History
- 2026-11-08 · First pass (65 tests): an unknown Agents value falling through to the balanced rule went uncaught (mutation `unknownrule` passed). Review then found that any byte change to the line confirmed `wide`, and a same-day restamp could never confirm. Fixed: trust now compares the parsed level and a normalised confirmation stamp, the stamp carries the time to the minute, and 11 tests were added, including `an unknown Agents value adds nothing to the working rules or the band`.
- 2026-11-08 · Re-review found two more ways past the stamp check: a planted unknown value (`w1de`, or a Cyrillic look-alike `widе`) kept no stamp, so a typo fix to `wide` confirmed it; and removing a stamp's colon or adding text after it read as a new stamp. Fixed: the stamp is read from any Agents line, and only as the zero-padded digits of the date and time after `confirmed`. 4 tests added; reverting either fix fails 3 tests ([mutations.txt](mutations.txt), round 3).
