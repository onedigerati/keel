## History
- 2026-11-09 · First pass: all six checks passed as tested. The correctness and security reviews found the evidence rule quadratic on long lines (a 100k whitespace run took 13.5 s; 20k masked headers on one line, 35 s); false positives on prose, markdown table rows, grep output of source and `undefined`, including this report quoting its own checks; a folded Set-Cookie carrying a session cookie past the first pair; escaped quotes ending a value early; untracked evidence added from a subdirectory skipping the rule; a case-sensitive path that also missed archived evidence; and a denial that pointed at `keel:allow-secret` instead of masking. Fixed: a linear scan, the credential-run rule, every cookie pair checked, escape-aware values, env, `curl -b` and single-line HAR forms, a repo-root path for untracked files, a case-insensitive path that includes `docs/plans/*/evidence/`, a masking-first denial, and more GitLab token kinds.
- 2026-11-09 · Second pass: all six pass; a 1 MB line scans in about 25 ms. One narrow false positive is left (prose with a header name, a colon and a long word holding a digit), and the reviews' format and route limits are open questions in the plan.
